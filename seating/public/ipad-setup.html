Join the restaurant Wi-Fi

Use the staff Wi-Fi so this tablet can reach the restaurant’s seating server.

2

Trust the restaurant certificate

Choose your device above to see the right certificate instructions.

Open this page in Safari. Download the seating certificate, then open Settings → General → VPN & Device Management and install the downloaded Pizza Ranch Seating profile.

Next, go to Settings → General → About → Certificate Trust Settings and turn on full trust for the certificate you just installed.

Open this page in Chrome and download the seating certificate below. In the tablet’s Settings, search for Install a certificate. It is usually under Security & privacy → More security settings → Encryption & credentials.

Choose Install a certificate → CA certificate (on some Samsung tablets, Install from device storage → CA certificate), then select seating-root.crt from Downloads. Confirm the certificate installation using the tablet’s screen lock if asked.

Return to Chrome and open Seating Manager below. Menu names vary by tablet; a managed device may require your administrator to install the certificate.

Download seating certificate

Only install the restaurant’s certificate on an authorized staff device connected to staff Wi-Fi. This download contains the local server’s public certificate, not a staff login.

3

Open Seating Manager

Open the app below. Use your own four-digit employee PIN. First time? Choose “Set or renew my local PIN” and verify your cloud account while internet is available.

Open Seating Manager

4

Add it to the Home Screen

Choose your device above to see how to add the shortcut.

With Seating Manager open in Safari, tap Share → Add to Home Screen. Keep “Open as Web App” on if shown, then tap Add.

With Seating Manager open in Chrome, tap the ⋮ menu → Install and create shortcut → Install. Depending on your Chrome version, choose Add to Home screen or Install app, then confirm.

Chrome installation help

You’ll have a Seating Manager icon that opens like an app. Add the seating app itself, not this setup guide.

Once set up, staff tablets on the same restaurant Wi-Fi share seating through the Pi even when internet is down. Guest QR check-in pauses during an outage.
